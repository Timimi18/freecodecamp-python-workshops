# freeCodeCamp Python Workshops Archive

Welcome to my centralized repository hosting the hands-on coding workshops completed throughout the freeCodeCamp Python curriculum. These projects represent guided, progressive development tracks focused on implementing foundational software engineering rules and algorithms.

## 📂 Completed Workshops Directory

### 🧪 Core Syntax & Control Architectures (Workshops 01 - 10)
* **`01_report_card_printer.py`** - Explores fundamental variable declarations, type checking, and explicit class validations.
* **`02_employee_profile_generator.py`** - Manipulates compound string transformations, indexing, string slicing windows, and f-string templates.
* **`03_employee_profile_validator.py`** - Utilizes core string methods, sanitization tools, characters slicing boundaries, and mutation techniques to scrub raw corporate text arrays.
* **`04_bill_splitter.py`** - Implements progressive arithmetic operators and formatting boundaries to divide transactional values.
* **`05_movie_ticket_booking.py`** - Builds deep nested conditional trees and boolean logic operators to manage custom business constraints.
* **`06_kitchen_inventory_tracker.py`** - Tracks state updates across functional programming borders while handling isolated local versus global scope boundaries.
* **`07_caesar_cipher.py`** - Executes string translation tables (`str.maketrans`) and shifting arrays to model basic encryption routines.
* **`08_pin_extractor.py`** - Iterates over complex multiline text structures using nested loops to parse implicit integer algorithms.
* **`09_medical_data_validator.py`** - Parses structural records against regex validation layers (`re.fullmatch`) to spot missing keys and faulty types.

* **`16_countup_recursive_stack.py`** - Employs numerical base cases and rising execution stacks to append integers to collections recursively.
